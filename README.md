# Recipe Nutritionist

Recipe Nutritionist — пет-проект на Python, который оценивает идею блюда по списку ингредиентов, показывает пищевую ценность продуктов и подбирает похожие рецепты. Проект построен на данных Epicurious, обученной модели scikit-learn и заранее подготовленных таблицах с нутриентами.

## Возможности

- предсказывает класс блюда: `bad`, `so-so` или `great`;
- выводит пищевую ценность ингредиентов в процентах от дневной нормы;
- подбирает похожие рецепты с рейтингом и ссылкой на Epicurious;
- генерирует меню на день: завтрак, обед и ужин.

## Структура проекта

```text

│   └── recipes.ipynb         # исследовательский ноутбук
```

## Установка

Создайте и активируйте виртуальное окружение, затем установите зависимости проекта:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -e .
```

Если нужно запустить или продолжить исследование в ноутбуке, установите дополнительные зависимости:

```bash
pip install -e ".[research]"
```

## Использование

Оценить блюдо по ингредиентам:

```bash
python src/nutritionist.py "milk, honey, jam"
```

Сгенерировать меню на день:

```bash
python src/nutritionist.py menu
```

В обычном режиме приложение использует кэш `datasets/nutrients_facts.csv`, поэтому ключ USDA API не нужен. Если удалить этот кэш и заново собирать данные о нутриентах, передайте ключ FoodData Central через переменную окружения `USDA_API_KEY`.

## Данные и модель

В основе проекта лежит датасет рецептов Epicurious. Ноутбук `src/recipes.ipynb` содержит исследовательский пайплайн: подготовку данных, фильтрацию признаков, подбор модели, сбор пищевой ценности и подготовку похожих рецептов.

CLI загружает обученную модель из `src/best_model.pkl`. Список признаков берётся напрямую из сохранённой модели, поэтому отдельный сгенерированный файл `filtered_dataset.csv` для запуска больше не требуется.
